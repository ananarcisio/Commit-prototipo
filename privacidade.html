Política de Privacidade

Última atualização: novembro de 2026

1. Quais dados usamos

  • Dados da conta: nome, nome de usuário, e-mail, tag e bio.
  • Dados de uso: desafios iniciados, progresso, favoritos, conquistas e links de repositórios entregues.
  • Preferência de tema (modo claro ou escuro).

2. Onde os dados ficam

Neste protótipo acadêmico, os dados ficam salvos apenas no seu navegador (localStorage). Eles não são enviados para um servidor do Commit!. Como a senha local não é criptografada, não use uma senha real de outros serviços.

3. Login com Google ou GitHub

Quando você entra com Google ou GitHub, usamos somente nome, e-mail, identificador e foto de perfil para criar ou reconhecer sua conta no Commit!. Não temos acesso à senha dessas contas.

4. Compartilhamento

Não vendemos nem compartilhamos seus dados com terceiros. Os links de repositório que você entrega são os que você mesmo informa.

5. Seus controles

  • Você pode editar seu perfil a qualquer momento na tela Perfil.
  • Você pode sair da conta pelo botão "Sair".
  • Para apagar os dados salvos, limpe os dados do site nas configurações do navegador.

6. Contato

Em caso de dúvidas, fale com o grupo responsável pelo projeto Commit!.
